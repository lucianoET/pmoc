05-01: o shell devolve cabeçalho e rodapé sem emitir a faixa de abas, porque o Mapa navega ligando e
desligando camadas na barra lateral e não tem abas no domínio dele. Não inventar abas aqui.

Atenção ao contrato: o shell gera um botão de sair que chama o nome global de saída, que
`exporNoWindow()` já publica; e não gera nenhum botão de troca de view, que é justamente a função que
este módulo não possui. É por isso que a lista precisa ficar vazia e não pode ser preenchida com as
camadas.

Restrições inegociáveis: nenhuma função de domínio do Mapa é alterada; o motor de mapa e os arquivos
de camada não são tocados; nenhuma aba é introduzida.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Configuração do módulo → HTML do shell | Nome e versão são interpolados e injetados no DOM |
| Handlers inline do shell → escopo global do módulo | O shell aciona funções por nome publicado no objeto global; nome ausente vira erro só no clique |
| Camadas de demonstração → interface do Mapa | Os dados das camadas vêm de arquivos estáticos de demonstração, não do Supabase |
| Navegador → PostgREST (Supabase) | A anon key é pública por design; a autorização real é RLS no Postgres e não muda nesta fase |
