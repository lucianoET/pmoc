|----------|-------------|
| Configuração do módulo → HTML do shell | Nome, rótulos de aba e versão são interpolados e injetados no DOM |

| Navegador → PostgREST (Supabase) | A anon key é pública por design; nenhuma migração SQL nesta fase |
