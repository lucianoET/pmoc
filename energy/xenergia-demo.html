Como plugar dados reais

Toda a camada de dados está isolada no objeto DADOS, no topo do arquivo. Substituir por consultas ao banco não exige tocar em nenhum gráfico.

Esquema mínimo

-- Leituras brutas: energia, água, qualquer grandeza
create table leitura (
  id           bigserial primary key,
  ponto_id     int  not null references ponto_medicao(id),
  instante     timestamptz not null,
  grandeza     text not null,   -- 'kwh' | 'kw' | 'm3' | 'nivel_m' | 'fp'
  valor        numeric not null,
  unique (ponto_id, instante, grandeza)
);

-- Pontos de medição: prédio, quadro, reservatório, entrada geral
create table ponto_medicao (
  id        serial primary key,
  nome      text not null,
  tipo      text not null,       -- 'energia' | 'agua'
  escopo    text not null,       -- 'geral' | 'predio' | 'quadro' | 'reservatorio'
  local_id  int references local(id)
);

-- Variáveis de normalização: sem elas não há EnPI
create table variavel_periodo (
  competencia   date primary key,   -- 1º dia do mês
  area_util_m2  numeric not null,
  efetivo_medio numeric not null,
  graus_dia     numeric not null,
  dias_uteis    int     not null
);

-- Fatura: fonte primária da Fase 1, anterior a qualquer sensor
create table fatura (
  competencia        date not null,
  tipo               text not null,      -- 'energia' | 'agua'
  consumo            numeric not null,
  demanda_registrada numeric,
  demanda_contratada numeric,
  fator_potencia     numeric,
  valor_total        numeric,
  primary key (competencia, tipo)
);

Campo novo exigido pelo indicador inverter

-- O inventário atual do PMOC não distingue velocidade fixa de inverter.
-- Sem estes campos o IPI não sai do papel.
alter table equipamento_climatizacao
  add column tecnologia_compressor text
    check (tecnologia_compressor in
      ('on_off','inverter','scroll_digital','vsd','desconhecido'))
    default 'desconhecido',
  add column ence_classe   text,      -- A..E, da etiqueta do equipamento
  add column ano_fabricacao int;

-- Índice de penetração inverter por escopo
select
  count(*) filter (where tecnologia_compressor = 'inverter')::numeric
    / nullif(count(*),0) as ipi
from equipamento_climatizacao
where situacao = 'operante'
  and tipo in ('SPLIT','PISO/TETO');   -- escopo de gestão

-- Fila de levantamento: o que ainda não foi para campo
select tipo, count(*) as pendentes
from equipamento_climatizacao
where tecnologia_compressor = 'desconhecido'
group by tipo order by 2 desc;

Campos de redundância

-- Sem isto, "35 inoperantes" e um numero solto: nao se sabe quais deixaram
-- um ambiente sem reserva.
create table grupo_redundancia (
  id       serial primary key,
  nome     text not null,          -- 'Paiol 3', 'F21 - Sala de baterias'
  local_id int  references local(id),
  regime   text not null           -- 'rodizio' | 'principal_reserva'
    check (regime in ('rodizio','principal_reserva'))
);

alter table equipamento_climatizacao
  add column grupo_id int references grupo_redundancia(id),
  add column papel    text check (papel in ('principal','reserva','unico'))
                           default 'unico';

-- Conjuntos que perderam a reserva: fila de reparo por criticidade,
-- e nao por ordem de abertura da OS.
select g.nome, g.regime,
       count(*) filter (where e.situacao = 'operante') as operantes,
       count(*)                                        as maquinas
from grupo_redundancia g
join equipamento_climatizacao e on e.grupo_id = g.id
group by g.id, g.nome, g.regime
having count(*) filter (where e.situacao = 'operante') < count(*)
order by g.nome;

-- Carga que NAO entra na demanda simultanea (reserva estrutural)
select sum(potencia_kw) as carga_reserva_kw
from equipamento_climatizacao
where papel = 'reserva' and situacao = 'operante';

Cálculo da VMN direto do xAguada

-- Vazão mínima noturna a partir da série de nível do reservatório.
-- Só é válida na janela em que as bombas estão comprovadamente paradas.
with janela as (
  select instante, valor as volume_m3
  from leitura
  where ponto_id = :reservatorio
    and grandeza = 'nivel_m3'
    and instante::time between '02:00' and '04:00'
    and instante::date = :dia
)
select
  (max(volume_m3) - min(volume_m3)) * 1000
  / extract(epoch from (max(instante) - min(instante))) * 3600
  as vmn_litros_hora
from janela;

Notas de implementação

Por que este arquivo não usa CDN

O Padrão Digital de Governo é distribuído via @govbr-ds/core por CDN (jsDelivr, SERPRO, Google Fonts). Numa rede de OM, depender de três domínios externos para a interface renderizar é risco desnecessário: se o proxy bloquear, o painel abre sem estilo nenhum.

A opção adotada foi reimplementar localmente os tokens do DSGOV — paleta institucional, escala tipográfica, espaçamento em múltiplos de 8 px, linguagem visual dos componentes — e os requisitos do eMAG. O arquivo é autocontido e funciona offline, como o PMOC Refrigeração v2.8. A família tipográfica é declarada como 'Rawline','Raleway',system-ui: se a aplicação hospedeira já carregar as fontes oficiais, elas são usadas; caso contrário, cai na fonte do sistema sem quebrar o layout.

Se a preferência for aderir ao pacote oficial, a troca é direta: incluir o core.min.css e substituir as classes locais pelos componentes br-*. A camada de dados e os gráficos não mudam.

Por que os gráficos são SVG escritos à mão

Pelo mesmo motivo: nenhuma biblioteca externa. São quatro funções de desenho (linha, barra, dispersão, barra horizontal) somando pouco código e sem dependência a atualizar. Se o volume de séries crescer muito, vale migrar para uma biblioteca — mas aí ela deve ser empacotada junto, não puxada de CDN.

O que falta para isto virar produção
  • Digitalizar 24 a 36 meses de fatura — sem isso não há linha de base e o gráfico de regressão é decorativo.
  • Cadastrar área útil por prédio e efetivo mensal na tabela de variáveis; hoje são constantes no código.
  • Confirmar a janela em que as bombas ficam comprovadamente paradas — a VMN só vale nessa condição.
  • Definir o nível de agregação de acesso irrestrito: curva de carga em resolução fina revela ritmo operacional.
